## 🌟 Overview

**CV Studio** is a modern, high-performance, ATS-optimized resume builder designed to help job seekers create publication-grade, recruiter-approved CVs in minutes. 

Featuring **24 handcrafted templates**, real-time ATS scoring, a strict **1-page A4 guarantee**, and instant high-resolution PDF download with clickable contact hyperlinks.

---

## ✨ Key Features

- 🎯 **24 Handcrafted Templates**: Tech Minimal, Executive Serif, Modern Dual-Tone, FAANG Standard, Creative Glass, Compact One-Pager, and more.
- 📊 **Real-time ATS Score Analyzer**: Instant grading based on action verbs, measurable metrics (KPIs), keyword density, contact completeness, and readability.
- 📄 **Guaranteed 1-Page A4 Layout**: Intelligent content scaling ensures your resume fits into a single, perfectly proportioned A4 page without awkward page breaks.
- 🔗 **Clickable Contact Hyperlinks**: Generates vector PDFs where LinkedIn, GitHub, Portfolio, Email, and Phone links remain active and clickable.
- 💾 **Data Safety & Export**:
  - Direct High-Definition PDF Download (Native Print Engine)
  - Full JSON Export & Import for offline backups
  - Quick-fill Sample Presets (Software Engineer, Product Manager, Designer, Marketing)
- 🎨 **Modern Dark & Light UI**: Sleek, glassmorphic workspace with zoom controls, template filter drawer, and live mobile preview.
- 🔒 **100% Privacy Focused**: Everything runs locally in your browser. No data is stored on remote servers.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/utsho261/cv-builder.git

# Navigate to the project directory
cd cv-builder

# Install dependencies
npm install

# Start the local development server
npm run dev
```
